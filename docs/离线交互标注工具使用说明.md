# 离线交互标注工具

交付日期：2026-10-16；工具版本：manual-review-1.0.0；标注格式：ecg-reference-v2。

直接用 Chrome 或 Edge 打开 [交互标注页面](../outputs/reference_review/blind/annotate.html)，也可从原复核包首页进入。无需服务器、联网或安装运行环境。移动复核包时请保留整个 `blind` 目录结构。

## 操作步骤

1. 选择 case，填写标注者代号，并选择是否曾看过该片段的算法标记。
2. 用“1秒 / 5秒 / 10秒”、滚轮和放大缩小按钮调整时间范围；滑块、左右箭头或“平移波形”用于移动视窗。幅值倍率单独调整，×1恢复当前视窗全幅。显示居中不改变原始采样值；放大导致裁切时通道旁会显示“裁切”。
3. 选择“点击标心搏”，在需要的位置点击。类型初始为“未知”；右侧可以先选类型再点击，也可以选中已有事件后选择类型并点击“应用”。八个通道上的竖线代表同一个全局时刻，不是八次标注。
4. 选择“拖选区间”，在右侧选择可判读或不可判读及原因，然后按下鼠标并拖至终点。区间采用左闭右开规则，不允许重叠或越出评价区。蓝色缓冲区只用于观察。需要调整区间端点时，删除所选区间后重新拖选；误删可撤销。
5. “选择 / 移动标注”可点击选择已有事件，再拖动到新的人工位置；侧栏列表也可选中事件或区间。删除、类型修改和移动均可撤销、重做。支持 Ctrl+Z、Ctrl+Shift+Z、Delete。
6. 点击“保存 JSON 文件”或按 Ctrl+S。程序自动写入 case、时间、全局采样索引、来源哈希、修订号和工具版本，不需要手写 JSON。文件进入浏览器下载流程；请确认已保存到磁盘。继续工作时选择同一个 case，使用“导入已保存标注”。

每次保存使用 `case_编号_r修订号_时间.json` 形式的新文件名，保留此前导出的版本。导入只接受本工具支持的格式，并检查 case、波形哈希、选样哈希、采样率、评价边界、重复事件及区间重叠；不匹配时不会改动当前标注。导入本身也能撤销。

## 位置与保存规则

- 点击坐标只取到最近的原始整数采样点，250 Hz时一个采样点为4 ms。**不搜索波形峰，不吸附厂商或算法预测。** “选择 / 移动”模式的命中范围只是为了选中已有人工标记，不会在添加标记时改变点击位置。
- 心搏位置记录为整条记录的全局采样索引，程序完成相对时间、视窗位置和屏幕像素的换算。缩放和平移不会改动已标位置。
- 搏动存在性、类型和把握程度分别保存，未知类型可以一直保留。页面不读取厂商代码或检测结果。
- 每次修改尝试保存浏览器草稿，同一浏览器和路径重新打开时可恢复；不同case分开存储。浏览器清理、隐私模式、缓存额度限制或移动目录可能使草稿不可用，因此**缓存不能替代下载的JSON文件**。缓存失败时会提示，仍可导出JSON。
- 撤销/重做针对本次打开后的最多100步操作；重新打开后恢复最终草稿，但不恢复撤销栈。每次修改及撤销都有修订号和时间记录。
- 标注时间采用ISO格式，`Z`表示UTC；导出文件另存浏览器时区及UTC偏移。程序使用标注电脑的时钟。
- 勾选“本case标注完成”前，需填写标注者、算法暴露情况，并明确覆盖整个评价区的可判读/不可判读区间。完成状态为“已完成但未裁决”，不自动成为已验收NN或临床真值。

## 本轮验证与文件范围

Chrome及Edge各通过11项浏览器测试：点击坐标、类型修改、移动、撤销/重做、区间及重叠检查、缓冲区限制、草稿恢复、版本化导出、导入来源检查、完成状态、缓存失败降级和DPR=2坐标。全部85个case通过本地文件加载检查，无联网请求、无算法结果请求。

85份显示用采样数据与既有NPZ逐字节一致。原始NPZ、空白参考模板、680张旧复核图的哈希未变。原静态首页保存在 `blind/index.static.html`，交互入口加入现有首页。本轮没有读取CCM或重新生成波形图片；测试截图仅用于界面验收。

实现源码在 `review_app/`；`scripts/build_review_app.py` 仅将既有NPZ转为浏览器可离线读取的精确int16数据，并复制界面文件。不会读取或修改用户浏览器草稿、下载的标注JSON及原始CCM。

构建记录：`outputs/reference_review/annotator_build.json`；数据校验：`annotator_integrity_checks.json`；浏览器测试：`annotator_test/test_results.json` 与 `annotator_test_edge/test_results.json`。测试目录中的模拟标注明确不属于人工参考。
