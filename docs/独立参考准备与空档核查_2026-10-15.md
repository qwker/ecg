# 独立参考准备与空档核查（2026-10-15）

已按修订版 README 第12节完成“没有外部独立参考时”的本轮工作：冻结选样、合并重复、准备无标记复核包、定位空档、整理类型与版本证据。尚未收到有相应心电判读能力的人员给出的参考，所有人工判读字段继续留空；没有冻结 NN 规则，没有试算正式 HRV，没有训练分类模型。

## 可直接使用的入口

- **给独立标注者：**[打开无标记复核包](../outputs/reference_review/blind/index.html)，并阅读包内 [README](../outputs/reference_review/blind/README.md)。整个 `blind` 目录可单独离线使用，不依赖服务器或联网。
- **给项目协调者：**[冻结选样清单](../outputs/reference_review/selection_manifest.json)、[长空档清单](../outputs/reference_review/gap_review.json)、[类型证据](../outputs/reference_review/code_mapping_evidence.json)。不要把这些文件提前交给盲法标注者。
- **参考完成后才用：**`outputs/reference_review/comparison/` 中的带标记图和算法事件位置。

## 1. 选样与去重

固定种子为 **20261015**。先写入 selection_manifest，再提取补充片段和绘图，没有按本轮图像结果替换样本。

| 集合 | 数量 | 规则 |
|---|---:|---|
| 定向问题集 | 13 | 原22个通道—片段项合并为14个记录片段，再合并同波形同位置的重复片段 |
| 常规对照 | 26 | 每个不同波形取1个剩余高一致片段；来源、记录均覆盖，4个时段分别7、7、6、6个 |
| 长空档抽样 | 35 | 7个≥300秒空档，各取左右边界及内部25%、50%、75%位置 |
| 类型码定位 | 11 | 定位15个事件实例，覆盖code1/2/3/6/13/99；同片段实例合并 |
| 合计 | **85个一分钟评价片段** | 覆盖26份不同波形；不是85名患者 |

39个片段直接复用原有NPZ；46个片段补读指定范围。没有重新执行27份的全程解析，也没有追溯40份缺元数据记录。压缩ZIP不支持廉价任意随机读取，跳到指定位置时底层可能解压此前前缀；本轮只保留指定片段，不因此宣称没有发生前缀解压。

每个片段都有：八通道原始计数NPZ、一张带缓冲边界的总览、六张连续10秒无标记图、一个本地HTML页面。共595张无标记图；另有85张带标记对照图及85份算法位置文件。相对秒数完整显示，采样索引换算为秒数×250；纵轴是原始计数，分图纵轴范围可能不同，均显示刻度。记录首尾不足10秒缓冲时保留真实边界，不补造信号。

无标记包使用 `case_001` 等编号，不显示原始record_id、精神障碍类别、选样理由、厂商代码或算法峰位置。映射保留在包外。NPZ只有采样值、采样率和起始索引。

## 2. 开发与保留集合的边界

按已有候选身份关系及完全重复NB哈希作连通分组，同一组不跨两侧。身份不能可靠分组者仅用于开发；已在上轮明确查看的三个问题示例也留在开发侧。

本次为 **23个波形/候选身份关联组、80个片段用于开发；3个关联组、5个片段暂作保留**。这不是已经确认的跨患者独立测试集，原因包括身份尚属候选、保留组过少、选样依赖既有算法诊断结果。不能据此宣称稳定泛化性能。

保留片段由独立人员先行标注并由协调者保管；在事件/NN规则固定前，不用其判读结果调整规则。若保留结果已经参与调参或被开发者查看，需记录暴露并降级为开发材料，另补未使用样本。

## 4. 类型与版本证据的新发现

本轮读取27份记录内的21份XML及53份配置成员，保存来源成员索引、SHA256、ZIP时间、配置报告状态和允许列出的分析字段；未把诊断文本写入复核包。详细来源在 `private/reference_review/report_version_evidence.json`。

- 两个重点长空档记录的XML `UnEffectTimePect` 分别为 **55.66%**（r_9e025…）及 **62.26%**（r_7e978…）。相应 `AnalysisTimeSeconds` 为68,381和26,517秒，原始跨度分别为73,020和70,260秒。前一份的“分析时长”与“无效比例”不能直接互换或相减解释；字段定义和精确分析区间仍未知，不据此建立有效NN掩码。
- code99在**全部27份记录中都恰好占据最初6行**，其最后一个位置最迟为起始后5.488秒。它与初始化有关是合理待检验假设；不能直接命名为正常、伪差或占位符，更没有自动删除这些事件。
- code13在本批仅发现1个事件，已为它准备上下文；单个实例不足以确定类型含义。
- 对15个选定事件按原行号重读BA/BD的对应行，确认BA第5整数与既存采样索引、BD第1整数与既存代码一致。**这验证的是提取一致性，不是两文件在生理语义上必然逐行对应。** 没有移行、改码或删事件来凑齐计数。
- code1/2/3/6的计数对照继续保留双零情况；code6计数相等仍不能自动确认事件类型。
- 顶层配置中没有可用的明确软件版本字段。颜色列表只有颜色值，不能提供类型名称。ZIP时间和报告状态也不能证明某个报告对应哪次BA/BD修订，版本关系继续待核查。

## 5. 验证、复现与当前停止点

新增三项边界测试覆盖：抽样不外推未查看区间、重叠及边界裁切、身份与相同波形的传递分组。交付检查逐一验证输入哈希、分组不跨侧、片段范围与复制哈希、图像可解码、本地链接、无标记包内容、参考留空、空档时长守恒和原RR表未改动。检查结果见 `outputs/reference_review/completion_checks.json`。

`prepare_reference_review.py --prepare` 只用于首次冻结；现有manifest存在时会拒绝静默覆盖。需要重画时使用 `--render`，只消费冻结清单，不重选样、不重读完整原始波形。新参考应另存文件，不覆盖模板。

本轮停止点符合README的无外部参考分支。下一项真正需要的输入是**这些固定片段的可判读区间、独立R峰位置和有依据的搏动类型**，不是补齐全部40份配置，也不是再写一个检测器。参考由具备相应判读能力的人员完成；用户不必自行猜测心电类型。

在参考完成并核验前，不应把空模板、算法一致或本轮工程检查当成可信NN；因此MeanNN/SDNN/RMSSD、全天HRV和分类仍保持未发布状态。
