# 核验产物字段与人工复核说明

版本：pilot-verification-v1。本文件定义的是候选 RR 和质量诊断产物，不是已经验证的 HRV 特征字典。正式 NN/HRV 尚未产生。

## 逐事件表

位置：`private/verification/beats/<record_id>.parquet`，每条候选事件一行。

| 字段 | 单位与口径 |
|---|---|
| record_id | 匿名记录编号；不等同于患者编号 |
| patient_id_candidate | 校验通过的来源身份字段产生的候选分组，未获研究编号确认 |
| event_index | 原始事件行号，从 0 起；不能因异常删除后重排 |
| sample_index | BA 第 5 个 int32 字段解释的采样位置，从 0 起 |
| offset_seconds | sample_index / 250 |
| event_time_local | 来源采集时间 + 偏移；缺来源时为空，无时区信息，不是 UTC |
| rr_ms | 当前与上一原始候选事件的采样索引差 ×4 ms；首行为空；长空档也原样保留，不能直接作生理 RR |
| vendor_code_raw / previous_vendor_code_raw | 当前与前一行 BD 原始类型码；含义未确认 |
| rr_change_gt20pct | 从第 3 个事件开始，abs(RR当前−RR前一)/RR前一 >0.20；只提示，不删除 |
| normal_beat_verified / nn_valid | 全部为空表示未知；不是 false，也不是可供训练的缺失值填补对象 |
| interpolated | 当前全部 false |
| source / validation_status | 字段解释假设与未验证状态；对应成员索引、哈希在 record_evidence.json |

## 5 分钟表

位置：`private/verification/quality_windows.parquet`。

| 字段 | 单位与口径 |
|---|---|
| grid | local_clock：按来源本地时间的 00/05/10…分钟对齐；relative_only：仅记录偏移，禁止用于昼夜分析 |
| window_start_local | 钟点窗开始时刻；缺采集时间时为空 |
| window_start_offset_s / window_end_offset_s | 半开区间 [start,end)，秒；首尾可能超出实际记录，实际覆盖单独保存 |
| payload_coverage_s | 该窗内实际存在的波形采样帧数 /250，不等于有效信号或 NN 时长 |
| full_payload_window | 是否有完整 300 秒载荷，不能当作质控通过 |
| event_count | 索引落在窗口内的候选事件数 |
| rr_ending_count | 右端事件在窗内且存在前一事件的候选间隔数 |
| rr_fully_contained_count | 两端事件均在窗口内的候选间隔数 |
| rr_crossing_left_boundary | 右端在窗内、左端在此前窗口的候选间隔数；不视作完整窗内 RR |
| rr_change_gt20pct_count | 右端事件在该窗内的相邻变化提示数量；不是全部异常间隔数 |
| all_channels_zero_fraction | 八通道同时为 0 的帧比例；不能识别所有噪声 |
| int16_extreme_sample_fraction | 所有存储样本中等于 −32768 或 +32767 的比例；仅是极值提示，不等同于已确认饱和 |
| constant_channels | 整窗最大值等于最小值的存储通道数；局部平线不会被此指标充分检出 |
| nn_coverage_s / longest_invalid_gap_s / window_pass | 全部为空，尚无经验证的 NN 或信号质量掩码，不能宣称已满足 18 小时等门槛 |

## 人工参考如何使用

`outputs/verification/independent_review_template.json` 中每项对应 60 秒待复核片段，NPZ 另外包含前后各 10 秒缓冲，存储全部 8 通道。正式逐搏参考尚未填写，图像目视查看不等同于完成参考标注。

先生成不带厂商/XQRS标记的八通道图。例如：

```powershell
.\.venv-ecg\Scripts\python.exe scripts/review_clip.py r_92e5bc2a63448166fbd1_43200 --offset 0
```

图像保存到 `outputs/verification/unmarked/`。`--offset` 是相对待复核 60 秒区间的秒数，每次画 10 秒，可用 0、10、20、30、40、50 依次查看完整片段。横轴为记录起点后的秒数，乘 250 得采样索引。通道标签只有存储编号，不能未经确认当作标准导联。

复制空白模板填写，不覆盖原模板：

- `human_r_sample_indices`：由波形独立定位的整条记录采样索引，严格递增，仅填在 review_start_sample 至 review_end_sample 的半开区间内。
- `human_beat_types`：与以上位置对应的人工类型；建议对象包含 sample_index、type、confidence、note；类型用 normal、abnormal、uncertain，无法判断不猜测。normal 必须有足够证据支持正常窦性搏动。
- `reviewer`：标注者代号；保存日期和所用片段版本。完整复核后才能改变 status。

参考标注阶段不看 `review/` 对照图或 detector_comparison.json。完成后再对照差异，复杂或不确定片段交由有资质的心电人员核验。只有得到参考事件后，才计算敏感度、阳性预测值以及正常类型混淆情况；当前算法间一致率不能替代这些指标。

后续 NN 计算必须同时检查相邻两端搏动类型及信号质量。删除异常事件后，不允许将缺口两边重新拼接为新的 NN；RMSSD 等也不能跨缺口形成相邻差分。
